
# Interactive Computer Graphics Algorithms

An interactive application for exploring fundamental computer graphics drawing algorithms through customizable visual demonstrations.

## Overview

This project demonstrates how basic geometric shapes are generated using computer graphics algorithms. Users can experiment with drawing settings and observe how different algorithms render lines, circles, and ellipses.

## Features

- **Line Drawing:** Demonstrates line drawing algorithms.
- **Circle Drawing:** Visualizes circle generation algorithms.
- **Ellipse Drawing:** Demonstrates ellipse drawing techniques.
- **Customizable Settings:** Allows users to adjust drawing parameters.
- **Interactive Visualization:** Helps users explore how computer graphics algorithms produce graphical output.
